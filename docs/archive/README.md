# Documentation Archive

This archive preserves project history without mixing it into the active
product documentation or backlog.

| Directory | Contents |
| --- | --- |
| `delivery-history/` | Completed roadmap, Pareto, web-client, onboarding, and status-report artifacts |
| `legacy-analysis/` | Generated specifications and capability analysis of the predecessor system |
| `legacy-context/` | Historical rationale about the predecessor system |
| `research/` | Dated market and product research |
| `superseded/` | Plans and implementation checklists replaced by newer planning |

Archive contents are read-only historical references. Paths, completion
markers, unchecked boxes, dates, and cross-references inside them are preserved
as they were and do not represent current project status. Current work is
tracked only in `../plans/product-cutover-plan.md`.
